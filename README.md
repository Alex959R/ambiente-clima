# Ambiente y Clima

App para registrar zonas, mediciones ambientales, alertas y recomendaciones,
con una funcionalidad de IA que interpreta las mediciones y sugiere
recomendaciones a la comunidad.

## Integrantes
- Alex - [@Alex959R](https://github.com/Alex959R)
- Andres  - [@AndresVS95](https://github.com/AndresVS95)

## Tecnologias
- **Backend:** Django + Django REST Framework + Swagger
- **Frontend:** React + Vite + TypeScript
- **IA:** (proveedor que usen, ej. Gemini) consumida como proxy desde el backend

## Estructura
- `backend/` - API REST en Django
- `frontend/` - Aplicacion React
- `docs/` - Bitacoras, presentacion y enunciado
